## Overview

This Epic covers all work required to allow customers to enrol in the loyalty
programme and view their loyalty status via the web and mobile dashboard.

## Epic Objective

Deliver the member enrolment flow and loyalty dashboard so that customers can
join the programme and track their points and tier status across all channels.

## Requirements

### EP-01
**Title:** Enrolment and Dashboard Epic Scope
**Priority:** High
**Status:** In Progress
**Description:** Deliver the end-to-end customer enrolment journey and the
personal loyalty dashboard on web and mobile. Includes the points balance display,
tier status indicator, and transaction history.
**Acceptance Criteria:**
- AC-01: Enrolment flow live on web and mobile
- AC-02: Dashboard accessible from account menu
- AC-03: All User Stories in this Epic accepted by Product Owner
**Traces To:** PRD-001/F-01, PRD-001/F-03

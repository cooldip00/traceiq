## Overview

This Technical Impact Assessment identifies all systems, services, and teams impacted
by the Customer Loyalty Program initiative.

## Impacted Systems

| System | Impact Level | Change Required |
|---|---|---|
| Customer Profile Service | HIGH | New loyalty_tier and points_balance fields |
| Order Management System | HIGH | Hook into post-purchase point accrual events |
| Payment Gateway | MEDIUM | Redemption flow integration |
| Notification Service | MEDIUM | New loyalty email templates |
| Analytics Platform | LOW | New loyalty events for reporting |
| Mobile App (iOS/Android) | HIGH | New Loyalty Dashboard screens |

## Risk Assessment

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| Customer Profile Service latency spike | Medium | High | Async points calculation via queue |
| Data migration for existing customers | High | Medium | Staged rollout by region |
| PCI-DSS compliance for redemption | Low | High | Engage security team in Sprint 1 |

## Architecture Constraints

- All loyalty events must be published to the existing Kafka event bus
- Points calculation must be idempotent to handle duplicate order events
- The loyalty service must be deployed as an independent microservice

## Requirements

### T-01
**Title:** System Integration Points Identified
**Priority:** High
**Status:** Approved
**Description:** All upstream and downstream system integration points must be
documented and validated with respective system owners before development begins.
**Acceptance Criteria:**
- AC-01: Integration spec reviewed and signed off by each system team lead
- AC-02: API contracts documented in the internal developer portal
**Traces To:** BRD-001/R-01

### T-02
**Title:** Non-Functional Baseline Established
**Priority:** High
**Status:** Approved
**Description:** Performance and reliability baselines must be captured for all
impacted systems before the loyalty service is deployed to production.
**Acceptance Criteria:**
- AC-01: Load test results documented for Order Management System integration
- AC-02: Rollback plan approved by the platform engineering team
**Traces To:** BRD-001/R-07
